PlayStation Access Controller Profile Editor

This local editor lets you organize button mappings for three controller profiles. Saving is simulated in this offline version; connect a compatible controller in the original web editor to write profiles over USB.

For the best experience with both PS5 and PC, configure shared profiles on your PS5. Button behavior can vary by game or software.
